#Glosario Conceptos basicos  de programación 

1. Algoritmo: Se trata de una secuencia ordenada de pasos  logicos diseñados para resolver problemas específicos o completar tareas determinadas. La lógica prevalece siempre.

2. Programa: Representa el conjunto de instrucciones codificadas que permiten a una computadora ejecutar una tarea concreta según las directrices establecidas. El software requiere precisión.

3. Código fuente: Consiste en el texto redactado bajo un lenguaje de programación específico que constituye la estructura base de un programa antes de ser sometido a procesos de compilación o interpretación. El origen es textual.

4. Lenguaje de programación: Comprende el sistema de reglas y símbolos empleados para construir las instrucciones que una computadora es capaz de procesar y ejecutar. Las reglas definen el lenguaje.

5. Sintaxis: Engloba las normas gramaticales que dictan la forma correcta en que deben redactarse las instrucciones dentro de un lenguaje de programación para que sean válidas. La estructura es obligatoria.

6. Variable: Designa un espacio de memoria con una etiqueta específica donde se almacena un valor susceptible de modificarse durante la ejecución de un programa. El dato puede variar.

7. Constante: Refiere a un espacio en memoria destinado a almacenar un valor fijo que permanece inalterable una vez ha sido definido dentro del código. El valor permanece estático.

8. Tipo de dato: Funciona como la clasificación que determina la naturaleza del valor almacenado en una variable, ya sea de carácter numérico, textual o booleano. La clasificación es técnica.

9. Operador: Representa el símbolo encargado de realizar operaciones matemáticas, lógicas o de comparación entre uno o varios valores. La acción es directa.

10. Expresión: Surge de la combinación de valores, variables y operadores que, al interactuar, producen un resultado único. Todo cálculo genera resultados.

11. Condicional: Estructura lógica que permite al programa bifurcar su ejecución y realizar distintas acciones basándose en la veracidad o falsedad de una condición. La decisión es binaria.

12. Bucle: Estructura de control que repite un bloque de instrucciones de forma cíclica mientras se mantenga activa una condición determinada. La repetición es necesaria.

13. Función: Bloque de código reutilizable diseñado para realizar una tarea específica, permitiendo la recepción de datos y la emisión de un resultado. El código debe reutilizarse.

14. Parámetro: Variable declarada en la definición de una función con el objetivo de recibir los datos que se proporcionarán durante su ejecución. La recepción es esperada.

15. Argumento: Valor concreto que se suministra a una función en el preciso momento de invocarla, correspondiendo directamente a los parámetros previamente definidos. El valor es puntual.

16. Retorno: Valor que la función entrega como resultado final una vez que ha concluido su proceso interno. La salida es fundamental.

17.Arreglo: Estructura capaz de almacenar múltiples valores del mismo tipo bajo un nombre común, organizando cada elemento mediante una posición o índice. El orden es clave.

18. Objeto: Entidad compleja que agrupa datos, conocidos como propiedades, junto con comportamientos definidos como métodos que guardan relación entre sí. La unidad es lógica.

19. Método: Función integrada dentro de un objeto que define las acciones o capacidades que este puede ejercer durante la ejecución. El objeto actúa solo.

20. Evento: Acción o suceso, tal como un clic del ratón o la pulsación de una tecla, que un programa es capaz de detectar y ante el cual puede reaccionar. La interacción es constante

1. Compilador — Programa que traduce todo el código fuente a lenguaje máquina antes de ejecutarlo, generando un archivo ejecutable.
2. Intérprete — Programa que traduce y ejecuta el código fuente línea por línea, sin generar un archivo ejecutable previo.
3. Depurador (Debugger) — Herramienta que permite examinar la ejecución de un programa paso a paso para encontrar y corregir errores.
4. IDE — Entorno de Desarrollo Integrado; software que combina editor de código, compilador/intérprete, depurador y otras herramientas en un solo programa.
5. Editor de código — Programa diseñado para escribir y editar código fuente, generalmente con resaltado de sintaxis.
6. Biblioteca (Library) — Conjunto de funciones y recursos reutilizables que un programador puede incorporar en su código para realizar tareas específicas.
7. Framework — Estructura o esqueleto de código que define reglas y proporciona herramientas para desarrollar aplicaciones de forma más rápida y organizada.
8. API — Interfaz de Programación de Aplicaciones; conjunto de reglas que permite que distintos programas o sistemas se comuniquen entre sí.
9. Repositorio — Espacio donde se almacena y organiza el código fuente de un proyecto, junto con su historial de cambios.
10. Control de versiones — Sistema que registra y gestiona los cambios realizados en el código a lo largo del tiempo, permitiendo volver a versiones anteriores.
11. Git — Sistema de control de versiones distribuido, usado para rastrear cambios en el código y coordinar el trabajo entre varios desarrolladores.
12. GitHub — Plataforma en línea que aloja repositorios de Git y facilita la colaboración, el almacenamiento y la gestión de proyectos.
13. Rama (Branch) — Línea de desarrollo independiente dentro de un repositorio que permite trabajar en cambios sin afectar el código principal.
14. Commit — Registro de los cambios realizados en el código en un momento específico dentro del control de versiones.
15. Merge — Proceso de combinar los cambios de una rama con otra, uniendo el trabajo realizado por separado.
16. Callback — Función que se pasa como argumento a otra función y se ejecuta después de que esta termina o cuando ocurre un evento determinado.
17. Programación síncrona — Modelo en el que las instrucciones se ejecutan una tras otra, esperando que cada una termine antes de continuar con la siguiente.
18. Programación asíncrona — Modelo que permite ejecutar tareas sin esperar a que terminen otras, continuando el flujo del programa mientras se completan en segundo plano.
19. JavaScript — Lenguaje de programación interpretado, usado principalmente para dar interactividad a páginas web tanto en el navegador como en el servidor.
20. TypeScript — Lenguaje de programación desarrollado por Microsoft que extiende JavaScript añadiendo tipado estático, compilándose finalmente a JavaScript.
